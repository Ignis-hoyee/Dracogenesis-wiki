# 快速开始

[卡尔老师的规则讲解](https://www.bilibili.com/video/BV169bs65Ebi/)

## 开局准备

### 地图设置

1. 放置中心地图。
2. 将10个地图板进行混洗。
3. 抽取3张地图板块，翻至B面，按图示进行拼接。
4. 根据玩家人数，抽取一定数量的地图板块，翻到A面，按下表所示方式进行拼接。
  
    | 玩家人数 | 拼接方式 |
    | --- | --- |
    | 2人游戏 | [2人游戏方案(占位符)](/public/images/tokens/2playersSetup.jpg) |
    | 3人游戏 | [3人游戏方案(占位符)](/public/images/tokens/2playersSetup.jpg) |
    | 4人游戏 | [4人游戏方案(占位符)](/public/images/tokens/2playersSetup.jpg) |

5. 若为4人对局时，最后1个剩余的地图板块翻至B面，作为空岛放置在边上，并在岛上带有狩猎奖励的地块各添加1个对应的临时资源。

### 纪年板块设置

1. 放置季节指示物到年历的第一年位置。
2. 将10个纪念碑任务板块叠一起盖放在一侧。

### 繁育轨设置

1. 将4分，8分，12分从低到高重叠，放到繁育轨板块的11格中位格子上。
2. 混洗技能牌、奇观牌形成牌库，技能牌库放到繁育轨道板块右上角，奇观牌库放到繁育轨道板块右下角。
3. 将技能牌，奇观牌从左往右放入繁育轨道的卡槽，直到填满卡牌。
4. 每个玩家拿取2个自己对应颜色的指示物，放置到繁育轨道左侧。

## 开始游戏

### 纪年设置

1. 抽取4个纪念碑任务，放置到纪年板块中间的空位上。纪念碑任务是获取得分的手段之一。
2. 每个玩家以自己喜欢的形式决定顺位，并选定一个颜色为自己的颜色，将对应颜色的木质圆柱放置到纪年板块左上角的顺位。决定3号位的玩家获得1个食物，4号位的玩家获得1个金币。

### 玩家设置

1. 玩家拿取自己颜色对应的角色面板，放到自己面前。
2. 拿取对应自己颜色的9个巢穴标记，正面放到自己面板上的巢穴槽上。
   - 巢穴格外围的符号为对应每个巢穴建造对应的筑巢奖励。
3. 拿取自己颜色对应的个龙米宝，其中5个放置到面板左上角的孵化槽上，余下4个作为自己初始使用的龙用作开局。
   - 孵化槽右侧的符号为对应龙孵化解锁时的孵化奖励。
4. 将8张[初始技能牌](/cards/skills/index.md#初始技能牌)作为每个玩家的基础牌组，然后抽取5张作为手牌。

### 巢穴设置

1. 以逆顺位形式（4号位、3号位、2号位、1号位）的顺序，玩家依次在海岸线（地图边缘，画有海浪的地图地块）开始摆放自己最左侧的巢穴并获得巢穴奖励。每个玩家的第一个巢穴距离只要要相隔4个地块以上才能放置。
